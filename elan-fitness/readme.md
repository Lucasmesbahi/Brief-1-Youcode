# Élan Fitness

## Présentation

Élan Fitness est un site web pour une salle de sport mixte. Le but du projet est de transformer le site one page en un site avec plusieurs pages.

## Les pages

* **Accueil :** présentation de la salle.
* **À propos :** informations sur la salle.
* **Programmes :** les programmes de sport.
* **Contact :** un formulaire pour contacter la salle.

## Technologies

* HTML
* CSS

## Fonctionnalités

* Navigation entre les pages.
* Design simple et facile à utiliser.
* Site responsive pour les téléphones, tablettes et ordinateurs.
* Formulaire de contact.

## Installation

1. Télécharger le projet depuis GitHub.
2. Ouvrir le dossier dans VS Code.
3. Ouvrir le fichier `index.html` dans le navigateur.
